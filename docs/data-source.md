These curated CSVs are transformed versions of the publisher’s source tables. The transformations select columns, normalize dates, aggregate payments and order items, select the latest answered review per order, translate categories and calculate delivery flags. The included SQLite database contains the same curated tables. Preserve attribution and the dataset license when sharing adaptations. No new rights over the original data are claimed. Check the publisher’s current terms and your intended use before public redistribution or commercial use.

No raw review comments, names, ZIP codes or geolocation rows are included. Public dataset identifiers remain in the model. Historical observations must not be presented as 2026 sales activity.

The project’s MIT license applies only to original scripts and report authoring code; it does not relicense the dataset.
